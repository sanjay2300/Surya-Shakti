# Surya-Shakti Solar Monitor

## Problem Statement
Managing and monitoring solar energy systems efficiently is difficult without a centralized tracking platform. This project helps monitor solar performance and energy usage effectively.

## Features
- Solar monitoring dashboard
- Energy usage tracking
- Performance analytics
- Real-time monitoring interface
- User-friendly UI

## Tech Stack
- Kotlin
- Android Studio
- Gradle

## Project Structure
- app/
- gradle/
- build.gradle.kts
- settings.gradle.kts

## Installation
1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle files
4. Run the application on emulator or device

## Future Improvements
- Cloud database integration
- AI-based energy prediction
- Live sensor support
- Advanced analytics dashboard
